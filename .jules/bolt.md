## 2024-05-24 - React Component Micro-optimization
**Learning:** In highly interactive React apps with long lists of complex components (like a chat application's message list), recalculating hover state by attaching `onMouseOver` and `onMouseLeave` handlers to every item (or even using event delegation to set a state variable) can cause significant performance problems due to React re-rendering.
**Action:** When a hover state only affects styling (like showing a timestamp or action buttons), use CSS `:hover` or Tailwind's `group-hover:` instead of managing hover state in React component state. This eliminates Javascript execution, event bubbling, and React reconciliation from the critical hover path, resulting in vastly superior performance, especially in large list components.
