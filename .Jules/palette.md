## 2026-09-03 - Add aria-label to copy ID button\n**Learning:** Interactive elements with only text hidden via truncation or without explicit text labels should have an aria-label to support screen readers, especially utility buttons like 'Copy ID'. Furthermore, adding 'type="button"' is a good practice to prevent accidental form submissions.\n**Action:** Always include 'aria-label' and 'type="button"' attributes on interactive elements in the Sidebar component.
